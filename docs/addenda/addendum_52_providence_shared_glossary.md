PROJECT PROVIDENCE
SHARED TERMINOLOGY & CONCEPT GLOSSARY
Version 2.0
Date: 2026-08-28

PROJECT PROVIDENCE
The overarching mission and system philosophy.

PERSONAL WORLD
The persistent AI environment associated with one client.

PORTAL
The interface through which the client enters the personal world.

PROJECT JARVIS
The operational studio and interactive environment through which Providence
is currently being built and experienced.

PERSONAL INTERACTIVE TV STATION
The broadcast experience inside the personal world.

ONE PERSON — ONE CHANNEL
Each individual may have a personalized broadcast channel.

ONE PERSON — ONE WORLD
Each client may have a personal AI ecosystem, not merely a feed.

AI NEWSROOM
The cooperating agents that discover, investigate, verify, analyze, edit, and
prepare information for presentation.

PERSONAL NEWS USHER
The primary client-facing partner, host, and orchestrator.

KUMBHAKARNA
The named system-level COO character.

PERSONAL AGENT
An agent instance assigned to one client.

AGENT LIBRARY
The canonical collection of agent-role blueprints.

TRAINER LIBRARY
The canonical collection of trainer-role blueprints.

FIRST NAME
The human-style identity component assigned from the approved global agent
name list.

LAST NAME
The role or system designation attached to an agent's first name.

AGENT_ID
The immutable machine identifier for an agent.

CLIENT_ID
The identifier binding a personal agent, profile, or world state to a client.

PERSONA
The presentation layer through which an agent speaks or appears.

PERSONA ENGINE
The subsystem that lets a persistent agent adopt different presentation
styles without changing its underlying identity, permissions, memory, or role.

REVERSE PSYCHOLOGY
Providence-specific usage: understanding why a person says or asks something
rather than responding only to literal wording.

RELATIONSHIP BEFORE CORRECTION
First understand the person and conversational purpose, then decide whether
correction is needed.

PATIENCE
The ability to let a person complete their thought before imposing an answer.

KINDNESS
Patience, attention, timing, restraint, humor, protection of the client's
interests, and an effort to leave the client better than before.

TRUTH-CHECKING
A broader process than fact-checking that may include context, framing,
contradiction, uncertainty, opinion, and speculation analysis.

SIGNAL
Information that may contain meaningful predictive, explanatory, or factual
value.

NOISE
Information that attracts attention but contributes little useful
understanding.

EXPLORER
An agent responsible for searching, gathering, retrieving, and investigating
information.

SPECULATOR
An agent responsible for monitoring chatter, detecting emerging signals,
generating hypotheses, and deciding what deserves investigation.

REPORTER
An evolved newsroom role combining discovery, investigation, evidence
gathering, challenge, synthesis, client relevance, and coherent reporting.

PERSONAL REPORTER
A Reporter assigned to one client and selecting news based on that client's
profile rather than global popularity alone.

EVOLUTION
The process through which an agent acquires broader capability, maturity, or
responsibility while preserving useful prior learning.

CAPABILITY
A specific skill an agent can perform.

ROLE
The organizational function an agent currently occupies.

ASSIGNMENT
The work an agent is currently performing.

STATUS
The agent's current work condition.

LIFECYCLE STATE
The agent's broader existence state.

CREATOR
The founding human authority that defines the mission, values, training
direction, and cultural direction of Providence.

CREATOR-FIRST DEVELOPMENT
The strategy of building and training the first personal agent world for the
Creator before generalizing the system for other clients.

CLIENT
The person receiving and interacting with a personal Providence world.

SHARED SUCCESS
The governing idea that the system should seek outcomes beneficial to the
Creator, agents, clients, and long-term health of the larger system.

COLLABORATION
The expectation that agents request, share, challenge, refine, and build upon
each other's work.

STUDIO
The visual and interactive broadcast environment inside the portal.

RUNNING COMMENTARY
Continuous human-friendly narration of what the system and its agents are
doing.

MEGAPHONE
The philosophical metaphor for AI-enabled power used to carry truth,
knowledge, and useful ideas farther.

DEVICE-INDEPENDENT WORLD
The principle that personal-world state belongs to the system, not to a
single device.

VERSIONING
Providence documents are living documents and may evolve as the system gains
new agents, governance, training, and operational experience.
